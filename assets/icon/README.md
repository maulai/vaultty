# Icon

A neon lock with a terminal prompt in the app colors.

| File | Use |
| --- | --- |
| `vaultty.svg` | main artwork with glow, source for 48 to 256 px |
| `vaultty-small.svg` | simplified artwork without glow, source for 16 to 32 px |
| `png/vaultty-*.png` | renders at 16, 24, 32, 48, 64, 128 and 256 px |
| `vaultty.ico` | all PNG sizes in one file, embedded in the Windows release binaries |

The SVG files are the sources. The PNG and ICO files are generated from them.
